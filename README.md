# 🏥 SPU Medbay (ระบบจัดการห้องพยาบาล)

**SPU Medbay** คือระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการห้องพยาบาลแบบครบวงจร ที่ถูกออกแบบและพัฒนาขึ้นจากความต้องการใช้งานจริง (User-Centered Design) ของบุคลากรทางการแพทย์ เพื่อยกระดับคุณภาพชีวิตในการทำงาน (Quality of Life - QoL) ของพยาบาล พร้อมทั้งเพิ่มศักยภาพและประสิทธิภาพการให้บริการด้านสุขภาพภายในมหาวิทยาลัยศรีปทุมอย่างเต็มรูปแบบ

## ✨ ฟีเจอร์เด่น (QoL Key Features)

- 📋 **ระบบบันทึกประวัติและการรักษา (Patient & Case Management)**
  รองรับการแตะบัตรนักศึกษา/พนักงาน เพื่อดึงข้อมูลเบื้องต้นเข้าสู่ระบบอัตโนมัติ (Auto-fill) (ต้องใช้ API จาก SPU-SCMS)พร้อมบันทึกข้อมูลสุขภาพพื้นฐาน ประวัติการแพ้ยา และรายละเอียดการรักษาได้อย่างรวดเร็วและแม่นยำ
- 🛏️ **การติดตามสถานะเตียงอัจฉริยะ (Smart Bed Management)**
  แสดงสถานะเตียง (ว่าง / กำลังใช้งาน) แบบเรียลไทม์ พร้อมระบบจับเวลาอัตโนมัติ และการแจ้งเตือนพยาบาลเมื่อผู้ป่วยใช้งานเกินเวลาที่กำหนด (Observation window)
- 💊 **การจัดการคลังยาและเวชภัณฑ์ (Inventory & Pharmacy)**
  เช็คและตัดสต็อกยาทันทีเมื่อมีการสั่งจ่ายในแต่ละเคส ลดปัญหาของหมดคลัง
- 📊 **ระบบรายงานเชิงวิเคราะห์ (Analytics & Campus Reporting)**
  สามารถออกรายงานวิเคราะห์ยอดเข้าใช้งานห้องพยาบาลแบบรายวัน/สัปดาห์/เดือน

## 🔒 ความปลอดภัยและมาตรฐานสากล (Security, Privacy & Compliance)

- **พระราชบัญญัติสุขภาพแห่งชาติ พ.ศ 2550 มาตรา 7 (RBAC : Role-Based Access Control):** การจำกัดสิทธิ์ผู้ใช้ระดับผู้ดูแลระบบและพยาบาล เพื่อรักษาความลับของผู้ป่วยตาม พ.ร.บ. สุขภาพแห่งชาติ
- **มาตรฐานอารยสถาปัตย์ไซเบอร์ (WCAG 2.2 Level AA):** หน้าจอถูกออกแบบให้มีคอนทราสต์ชัดเจน อ่านง่าย รองรับการเข้าถึงสำหรับทุกสภาพร่างกาย
- **Audit Trail:** ระบบบันทึกประวัติการเปลี่ยนแปลงข้อมูลอย่างละเอียด (เช่น พยาบาล ก. แก้ไขข้อมูลผู้ป่วยเมื่อเวลา 10.00 น.) ตรวจสอบย้อนหลังได้ตลอดเวลา
- **OWASP Top 10:2025:** พัฒนาระบบภายใต้กรอบมาตรฐานความปลอดภัยระดับสากล (เช่น การป้องกันช่องโหว่จากการฉีดโค้ด (Injection) หรือ การควบคุมสิทธิ์ที่หละหลวม) เพื่อป้องกันและลดความเสี่ยงจากการถูกโจมตีทางไซเบอร์

## 🔮 แผนการพัฒนา (Roadmap)

- **IoT Room Control Panel:** ศูนย์กลางควบคุมอุปกรณ์อัจฉริยะสภาพแวดล้อมภายในห้องพยาบาล (เช่น สั่งเปิด-ปิด แอร์, พัดลม, ปรับลดแสงไฟ) ทำงานจบครบในหน้าเว็บเดียว
- **SPU-SCMS Integration:** เชื่อมต่อและบูรณาการฐานข้อมูลร่วมกับระบบ SPU-SCMS เพื่อการดึงข้อมูลนักศึกษาและบุคลากรแบบอัตโนมัติ

## 🛠️ เทคโนโลยีที่ใช้งาน (Tech Stack)

- **Backend:** Python 3.11+, 
- **Frontend:** HTML5, CSS3, JavaScript (เน้น UI ที่เป็นมิตรและตอบสนองเร็ว)
- **Database:** SQLite (สำหรับการพัฒนาและการทดสอบ) 
- **Logs:** Django Simple History
- **Deploy/Hosting:** Heroku

## 🚀 ขั้นตอนการติดตั้งและรันโปรเจกต์ (Local Setup)

รองรับการทำงานในสภาพแวดล้อม **Windows PowerShell**:

1. **สร้างระบบจำลองสภาพแวดล้อมเพื่อจัดการแพ็กเกจ (Virtual Environment)**
   ```powershell
   python -m venv .venv
   ```

2. **เปิดใช้งาน Virtual Environment**
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. **ติดตั้งไลบรารีที่จำเป็น (Dependencies)**
   ```powershell
   pip install -r requirements.txt
   ```

4. **สร้างโครงสร้างฐานข้อมูล (Run Migrations)**
   ```powershell
   python manage.py migrate
   ```

5. **จำลองข้อมูลเริ่มต้นเพื่อพร้อมทดสอบระบบ (Seeding Data)**
   ```powershell
   python manage.py seed_initial_data
   ```

6. **เปิดใช้งานเซิร์ฟเวอร์ (Start Development Server)**
   ```powershell
   python manage.py runserver
   ```

หลังจากเซิร์ฟเวอร์ทำงานเสร็จสมบูรณ์ สามารถทดลองใช้ระบบได้ที่เบราว์เซอร์: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
